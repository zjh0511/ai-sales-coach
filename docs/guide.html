Google AI Studio 免費 API Key 申請教學

全程免費、不需要信用卡，大約 3 分鐘。

為什麼要自己申請？

因為 AI 用量是算在金鑰持有人的帳號上。每個人用自己的金鑰， 額度就不會互相搶，你的練習內容也只會經過你自己的帳號。

1

用 Google 帳號登入 AI Studio

用手機或電腦打開下面的網址，用你平常的 Google 帳號登入即可，不需要另外註冊。

開啟 Google AI Studio →
如果畫面出現同意條款的視窗，勾選同意後才會看到建立金鑰的按鈕。 公司或學校的帳號有時會被管理員停用這項服務，那就改用個人的 Gmail。
2

按「Create API key」建立金鑰

頁面標題是 API keys。找藍色的按鈕：

  • 英文介面：Create API key
  • 中文介面：建立 API 金鑰
如果它問你要放在哪個專案（Select a Google Cloud project）， 直接選它預設帶出來的那一個就好，或按 Create API key in new project。 不需要開通付費、不需要綁信用卡。
3

複製整串金鑰

建立成功後會跳出一串英數字，按旁邊的複製圖示，或長按選取全部複製。

要複製「完整」的一整串，中間不要漏字、前後不要有空白。
金鑰的開頭不一定是 AIza——Google 已改用新的格式， 看起來不一樣是正常的，照複製就好。
這串金鑰之後還看得到：回到同一個頁面就能再複製， 所以不用特別存到別的地方。真的忘了就刪掉舊的、重新建一把。
4

回到 AI業務教練貼上

回到 App 的登入畫面，服務商選 Google Gemini，把金鑰貼進輸入框， 按「驗證並登入」。

系統會真的去 Google 驗證一次，所以貼錯或選錯服務商當下就會告訴你， 不會等到練習到一半才出問題。

常見問題

會花錢嗎？
Gemini 有每日免費額度，正常練習用不完，也不需要綁信用卡。 額度用完時 App 會自動改用較小的模型（不會壞，但回饋品質會降一些），隔天恢復。

金鑰會被別人看到嗎？
不會。金鑰只存在你這台裝置的瀏覽器裡，這個網站沒有後端可以收， 我們也看不到。共用裝置用完請按首頁下方的「登出／更換金鑰」。

我的練習內容會外流嗎？
你輸入的內容會送到 Google 的 AI 服務產生回應，這點跟你直接用 ChatGPT 一樣。 但請不要輸入客戶的真實姓名、電話或身分證號，演練只需要性別、年齡與大略背景。 上傳的文件與訓練紀錄只存在你自己的裝置。

可以跟同事共用一把金鑰嗎？
技術上可以，但不建議——一個人用完額度大家都不能用，而且免費額度本來就夠個人練習。

「金鑰無效」是什麼意思？
多半是三種情況：複製時漏字、上方選錯服務商、 或這把金鑰是舊格式（Google 自 2026 年 9 月起不再接受舊的 Standard key）。 最快的解法是回 AI Studio 重新建一把。

換手機要重新申請嗎？
不用。同一把金鑰可以在多台裝置使用，回 AI Studio 複製同一串貼上就好。 但訓練紀錄與上傳的文件存在裝置本機，不會跟著過去。

本教學所描述的畫面是 Google 的服務，Google 可能隨時調整介面文字與流程。 若實際畫面與此處不同，請以 Google AI Studio 上的說明為準。

# 聲音評估改版（2026-09-10）

## 原因與變更

舊版僅將語音辨識的文字送给模型，沒有音訊，因此不應推測聲音星等。新版在模擬練習的對話頁提供未預勾的「本場聲音評估」。同意後使用「開始語音對話」，才同步暫存使用者的發言。單句語音輸入、打字、AI 朗讀不納入錄音評分；教練示範模式不替客戶角色評業務能力。

瀏覽器以 AudioWorklet 收取單聲道 PCM，編成 16 kHz、16-bit WAV，無外加套件或模型下載。每句最多 45 秒、本場最多 180 秒，顯示收錄句數。錄音在辨識完成後、發送對話前停止，不收錄模型等待與 AI 播放。每句對話仍只有原有的一次模型請求。

結束後先沿用完整逐字稿合規檢查與兩項文字評分，再追加一次同模型音訊請求，評估流暢度、語調親切感、表達穩定與明確程度（原「自信心」欄位）。聲音欄位標示音訊依據及片段秒數；空白、近乎靜音、證據不足不得硬給星等。自信心不代表內在心理或人格。星等是 AI 教學參考，尚未完成真人評分校準。

## 資料與失敗處理

- 音訊僅暫存本頁記憶體，不寫入 localStorage 或 App 資料庫。經已驗證帳號的後端轉送 Google Gemini。Google 自身的保存政策依服務條款。
- 成功後清除本頁音訊；取消勾選、重整、換場、登出也清除。失敗保留本頁音訊供手動重試，文字回饋仍可看。
- 後端只接受指定聲音端點的有限大小 JSON 與經驗證的 PCM WAV；其他表單原有大小及個資限制不變。檢查回合範圍、重複回合、格式、時長、同帳號場次、評分秒數及星等。
- 後端只加密保存評分，不保存音訊；已成功的音訊評分會快取，避免重複消耗額度。
- 維持 Google 單一路徑、原本選定模型與免費方案確認，不換付費模型。音訊評估也會使用 Gemini API 額度。
- 舊場次未錄音，無法事後還原聲音。換場後需重新同意。

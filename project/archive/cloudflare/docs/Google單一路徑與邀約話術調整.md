# Google 單一路徑與邀約話術調整

2026-09-10，依使用者最新要求實作。

## Google AI Studio 單一路徑

- 設定頁只需輸入 Google Key、載入 Gemini 模型、確認免費方案並保存。移除平台下拉選單、其他平台教學與 OpenRouter 本機匯入按鈕。
- 首頁、登入、申請指南與隱私說明同步更新。既有 Google 金鑰加密保存與模型記憶維持原流程。
- 後端拒絕非 Google 的驗證、模型載入及生成；舊平台連線不再出現在可用清單，不能藉舊 ID 繼續發送。舊加密資料未自動刪除，帳號資料刪除仍依原功能處理。
- 其他平台教學圖片移至 artifacts/retired-tutorials，未納入公開網站。約減少 90,099 bytes。未開啟付費方案，未發布 GitHub Pages。

## 邀約範例與示範方式

- 自我介紹使用「我是 OO 人壽的 OO」，不把品牌教練名稱當業務姓名，也不生成真實姓名。
- 4–6 行業務／客戶來回示範，不是整段單向推銷。程式整理角色換行；範例必須包含客戶回應和業務接續。
- 運用 NLP 入門溝通練習常見的跟隨再引導、適度沿用對方用詞、確認理解、開放提問與選擇空間。重點是尊重與親和感，不宣稱能控制心理或保證成交。
- 直接回答客戶問的來意、時間等具體問題，不用冗長的同理旁白。提出小而明確的邀約，允許拒絕或改天；不假裝熟識、不捏造過往聯絡、不隱瞞保險面談目的。
- AI 扮演業務的示範沿用相同溝通原則。演練時不做即時學員合規審查，結束後統一查核的機制維持。

## 驗證

- 自動測試涵蓋非 Google 網路呼叫攔截、舊金鑰隔離、已移除匯入路徑、免費確認、指定 Gemini 模型、遮罩自介與來回結構，以及原有登入／語音／事後查核功能。
- 使用已確認免費的 Gemini-3.5-Flash-Lite 與虛構資料，實測「初次接觸」和「朋友或熟人」，均產出可核對的範例並通過既有獨立查核。結果存於 artifacts/rapport-examples-live.json。
- 生成品質仍可能變動；本輪不是 NLP 成效研究，也未測量實際成交率。

請重整 Chrome 後新開一場演練，重新取得參考範例；已生成的舊場次範例不會被悄悄改寫。

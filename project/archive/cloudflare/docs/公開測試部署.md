## 2026-09-13 驗證結果

- GitHub Pages 建置狀態為 `built`，版本 `702e3fd4bb8bf4eead6326b3809eacc67d703950`。
- 公開首頁可由 Chrome 正常載入。
- 後端 `/api/config` 回傳 HTTP 200，顯示正式登入已設定且維持免費模式。
- 從 `https://zjh0511.github.io` 發出的正式來源請求已取得正確 CORS 回應；登入預檢回傳 HTTP 204。
- Google OAuth 已授權 `https://zjh0511.github.io`；Firebase Authentication 已新增 `zjh0511.github.io`。
- Google Auth Platform 為「實際運作中／外部」，同事不需要逐一加入測試使用者。
- Cloudflare Workers 不接受 `fetch` 的 `redirect: error` 選項，初次公開登入因此在 Firebase 身分確認階段失敗；已改用 `manual` 並拒絕任何重新導向回應。部署版本為 `3b087bc9-5fb3-4659-8ff9-257da487ca81`。
- 公開版已用 Google 帳號完成登入，頁面正確顯示使用者姓名，登入後可進入 AI 與語音設定。手機麥克風權限仍由每位實際使用者在自己的裝置同意。

## 更新公開版

先執行測試與 `node scripts/build.mjs`，再執行 `node scripts/prepare-pages.mjs`。只將 `.private/pages-release` 的內容推送至公開存放庫，禁止上傳 `.private` 其他內容、API Key、Vault Key、原始 GPT 提示詞或內部工作文件。

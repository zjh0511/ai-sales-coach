# 第一輪後停住：語音生命週期修正

## 程式可重現的缺口

舊版 final 辨識結果到達後立即清除 recognition，但裝置尚未送出 onend，後續又等待 recognitionReleased。這會遺失仍在執行的麥克風控制，漏送事件時導致下一輪無法繼續。另有非預期 aborted 事件被吞掉、送出訊息時無條件取消朗讀、重複開始可能干擾原回應等缺口。這些是程式層級發現，尚未取得使用者手機的事件記錄確認單一實機根因。

## 修正

- 保留辨識器直到 onend，只在完整結束後送出 final 文字；重複通知不重送。
- 啟動與結束辨識都有有限等待；異常時釋放麥克風，顯示可持續閱讀的原因，不停留在假性進行中。
- 只取消仍在播放的朗讀，不在每次送出訊息與開始收音時任意重設語音合成器。
- 裝置已送出 onstart、且連續兩次觀察確認播放與佇列均閒置、沒有暫停時，才補足漏送 onend 的接話流程。
- 語音對話進行中不可重複開始；重複完成事件不重送 API，停止後的舊回呼不可影響新場次。
- 首次驗證 Key 預設為官方清單中的 gemini-3.5-flash-lite。既有已保存連線仍保留模型，需到設定重選並保存。

官方模型 ID 來源：https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite

## 驗證

58 項自動測試通過。新增實際 Voice + Conversation 的五輪整合模擬，以及收音漏送結束、非預期中止、播音漏送結束、暫停音訊、重複事件、停止後遲到回呼。這些測試模擬瀏覽器音訊事件；不等同真實 iPhone／iPad 聽感、麥克風與權限驗證。

公開版本識別：20260917-voice2；包含模組網址與 Service Worker 快取更新。

# 語音、主題與效能調整驗收

## 已完成
- 頂端提供淺色／暗色切換，偏好保存於該瀏覽器。登入頁豪老師在淺色使用深金棕色，在暗色使用淺金色，均已檢視。
- 新增「開始語音對話」：辨識結束後只送出 final 文字，教練播放完才開始下一次收音。保留單句語音輸入與手動送出。停止、離開頁面、隱藏分頁會取消後續收音；AI 回應期間停止按鈕仍可按。空白辨識、權限或供應商錯誤暫停自動模式，不無限重試。
- 一般對練由三次模型呼叫減至兩次：生成與獨立查核。查核只以最新使用者語句判斷是否合規，不把歷史已修正語句重新判成當前違規。查核拒絕時不把回覆寫入演練。
- 每次實質操作仍先上全國法規資料庫取得正文。送給三平台模型的法規內容改為已驗證相關原文段落，保留引用驗證。
- 每個操作共用一次模型清單查詢，下一個操作重新查驗，無跨帳號清單快取、不自動切換付費。
- 短對話輸出上限為 900 tokens，查核 350 tokens，其餘 2000 tokens；OpenRouter 原本統一 6500。達上限仍提示失敗而不顯示截斷內容。
- Groq 429 僅當 Retry-After 不超過 2 秒時自動重試一次，不再隱藏等待最多 30 秒。
- 429 區分單次文字超限、每分鐘限制、每日限制與供應端限流。判讀 metadata.raw，但不顯示原始回應或秘密。

## 驗證與限制
- 26 項自動測試通過；建置成功，初始文字殼壓縮約 31 KB，public 約 1781 KB（主要為使用者 App 圖示）。

- 麥克風實體收音、Chrome 停頓斷句與使用者聽感仍需試用；此為輪流說話模式，不是可同時說話或任意插話的全雙工通話。
- 未部署 GitHub Pages。

## 試用
1. 在 Chrome 開啟 http://127.0.0.1:8787/ ，按 Ctrl+Shift+R。
2. 右上角切換淺色／暗色。
3. 登入並在設定選擇自己的免費模型。
4. 電話約訪完成情境與範例後，按「開始語音對話」，同意收音再開始。說完等待教練回應，教練說完將接續收音。
5. 停止時按「停止」；辨識不清或供應端限流時改用文字或暫停再試。

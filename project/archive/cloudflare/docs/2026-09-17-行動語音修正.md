# 行動語音與預設模型

- 開始對話時，在使用者點擊事件內同步朗讀「語音已開啟，請開始說話」，讓行動瀏覽器先啟動朗讀；播完才開始收音。
- 每次朗讀重新讀取裝置音色，優先台灣中文，沿用裝置可提供的中文音色。音色延遲出現時自動更新設定選单，不清除 API Key 表單。使用者從其他裝置留下的音色不存在時，自動使用目前裝置中文音色。
- 每次使用者說完即可送出文字，但開始播放 AI 回覆前等待辨識器真正結束，避免麥克風與播放交接衝突；AI 說完後等待 300ms 再收音。
- 短暫安靜或 no-speech 會自動接續聆聽，不發出 AI 請求；連續 12 次空白、權限或網路錯誤仍會暫停，停止與離開頁面會取消待執行的重新收音。
- 朗讀啟動失敗會顯示提示，提供「播放上一句並繼續」恢復操作，不重送對話或消耗額外 AI 請求。
- 首次驗證 Key 時，只在官方回傳清單包含 gemini-flash-lite-latest 時預選；清單未包含時提示手動選擇。已保存連線的重選模型流程保留上次模型。

驗證：53 項自動測試通過，包含多輪接話、停止競態、音色延遲載入、辨識器釋放順序與預設模型。未在真實 iPhone／iPad 上測試麥克風與播音；Web Speech 的支援及播放限制仍取決於裝置與瀏覽器。

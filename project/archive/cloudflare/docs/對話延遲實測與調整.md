## 已實作

- 一般邀約的合規判定與回答合併為同一次生成。只有模型明確標示可走一般路徑、判定 clear，且伺服器未發現需複查的訊號時，才省略獨立查核。
- 商品承諾、利益誘導、法律稅務理賠、角色疑慮、長上下文、欄位缺漏或非 clear 判斷，仍進行独立查核；未通過就不播放、不記入成功對話。完整上下文納入升級判斷；關鍵字只決定是否複查，不直接判違規。
- 很窄的明確退佣完整句型，直接使用程式內的固定教練提示，標為合規疑慮並提供重說版本。只適用學員扮業務；否定、引用、問題與不明確句型不走此路徑。這不是全面的規則判法系統。
- 所有路徑仍先取得本次官方條文。引用原文由伺服器核對帶入；查詢失敗就暫停，未使用過期來源替代。
- 精簡角色提示，官方原文只傳一份；Gemini 3.1/3.5 Flash-Lite 明確使用 minimal 思考。官方文件顯示 minimal 本來就是這兩款的預設，不能宣称這個參數本身必然加速。
- 語音辨識收到完整 final 語句立即送出，不再額外等待 onend；未完成的辨識文字不送出。停止、重複通知與遲到的回覆不會重啟收音。

## 驗證與限制

32 項自動測試通過，包含一般單輪、風險複查、否定與引用不套退佣模板、查詢失敗攔截、停止與防重複送出。公開檔案建置成功，本機網站已提供新版語音模組；未發布 GitHub Pages。

一般路徑現在依賴同一輪模型的判定與伺服器升級規則，不再是每句兩個獨立模型判斷。這是效能與獨立複查覆盖範圍的取捨，不能保證偵測所有違規。涉及風險的長對話仍可能每句複查，因此仍可能慢。

本次沒有操作真人 Chrome 麥克風做端到端測試。請重整 Chrome 並開新場次試用。外部服務延遲和複查逾時仍未消除，不能宣稱已達即時語音或自訂 GPT 語音相同體感。後續應以實際模型服務穩定度再決定是否另選免費模型，不能未經使用者選擇就自動換模型。

# 平台連線與 Hao+ 品牌修正

- Google：移除只接受 AIza 前綴的本機限制，最大長度改為 2048，交由官方 API 驗證；權限錯誤與格式錯誤分開顯示。尚未取得使用者這把 Google Key 的成功驗證結果，不保證其權限正常。
- Groq：以使用者已保存、已確認免費的 qwen/qwen3.8-27b 測試。最初確認為每分鐘 Token 限制；縮減來源文字為本次官方條文摘錄、調整輸出預算，並依官方規格設定 reasoning_effort=none。修正後痛點分析 HTTP 200，返回三項結果。短暫限速依 Retry-After 等待至多 30 秒並重試一次，不換付費模型。
- OpenRouter：以即時價格判斷零價格模型，不再強制名稱以 :free 結尾；仍排除收費或價格不明項目、不適合對話的安全分類器，以及會自動選模型的路由器。當日官方目錄 Qwen3.8-27B 與 MiniMax M3 均有非零價格，不納入免費清單。
- 視覺：直接使用提供的 APP圖標.png，原圖不改繪。採深藍、亮藍、暖金，主要內容 17px、提示 15px、按鈕 16px，窄視窗改單欄。原圖約 1.54MB，因此整份公開資產約 1.77MB；主程式及樣式壓縮約 29KB。沒有加入大型介面套件。
- 驗證：15 項測試通過，尚未部署 GitHub Pages。

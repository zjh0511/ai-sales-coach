- 客戶文字欄位與貼圖阻擋；前後端檢查識別資料。自動偵測無法保證涵蓋所有個資，使用者仍需只填概括背景。

## 已驗證與尚待真人驗收

真實 OpenRouter 免費模型已完成痛點分析與約訪流程測試；詳細逐項結果保存在 artifacts。免費模型可用性、速度與額度會變動，錯誤會顯示給使用者，不偷偷切換付費模型。Groq 已驗證金鑰與模型列表，但未進行其推論收費狀態確認；Google 未提供測試金鑰，未做真實推論。

本機可列出三個 zh-TW 聲音，朗讀完成事件已驗證。**麥克風實際收音、辨識準確度、揚聲器聽感仍需使用者親自測試**。Web Speech 由裝置／瀏覽器提供，無法承諾所有手機或未來瀏覽器永遠支援。

目前回饋只對逐字稿可支持的「內容掌握」「專業度」評星；流暢度、親切感、自信心顯示無法評估。完整五項聲音評分尚未完成，不能視為正式版本已達成。

真實 Google 登入與 E-mail 註冊／驗證需要本人完成；我們沒有代建帳戶或寄送測試信。現有 Firebase 設定的唯讀連線檢查已完成。登入過期時需重新登入。

目前官方查核只涵蓋上述保險招攬規則；稅務、個案理賠與其他法律的搜尋和多來源核對尚未完成，因此即時討論維持開發中。

## 發布前的必要工作

本輪驗證補充：12 項自動測試通過，包含修正說法獨立判定、提前結束防護、語音停止後舊事件不復活。真實模型已通過痛點、範例、客戶回應、違規提醒、修正後繼續；回饋曾因格式或缺少引用被攔截，使用同場次重試後成功，示範模式與結束場次保護也通過。**免費模型回饋穩定度仍有改善空間，不能宣稱一次全流程零失敗。**

本機預覽可先驗收；正式發布前須再做多情境內容品質測試。已知依據現在直接帶入表單原文，避免模型把推測寫成事實。手機版已確認無橫向溢出，前端含教學圖共約 265KB，主要程式與樣式壓縮約 28KB。

1. 使用者確認本機版功能、語音與內容品質。
2. 經使用者批准後建立免費 Worker／D1，設定加密秘密、網站來源限制與 Firebase 授權網域。
3. 驗證雲端帳戶隔離、跨站 Cookie／身分驗證、到期清理、限流、備份與刪除規則。Worker 目前是待部署的程式，尚未做雲端實測。
4. GitHub Pages 只發布 dist；不可公開原始金鑰、.private、原始 GPT 提示詞或工作文件。設定前端後端網址後再做正式環境測試。
5. 使用者再次同意後發布。現階段沒有部署、沒有啟用付費服務。

## 免費方案與未來可能費用

| 用途 | 初期安排 | 未來可能費用／限制 |
|---|---|---|
| 網頁靜態檔案 | GitHub Pages 免費條件內 | 僅承載前端，無法自行執行後端 |
| 登入 | 現有 Firebase 免費方案 | 配額依方案與驗證方式；啟用額外服務前重新估算 |
| 金鑰與短期演練資料 | Cloudflare Workers + D1 免費方案 | Workers 免費每日 10 萬請求、每次 10ms CPU，須實測加密與查核是否符合；付費 Workers 起價 US$5/月，另有超量費及資料庫費 |
| AI 文字 | 使用者自己的免費模型／免費額度 | 非無限；OpenRouter 僅列零價格 :free 模型，Google/Groq 需確認帳戶方案；限額時停止，不自動購買 |

上述 US$5 是方案起價，不是整套 App 的保證月費。正式開啟任何付費服務前，另以使用人數、每月場次、每場輪數、保存期限提出預估並取得同意。

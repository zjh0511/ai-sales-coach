# 事後查核改版驗收（2026-09-10）

依使用者最新決定，取代先前「每句查核」與「風險句額外查核」設計。先前《對話延遲實測與調整》保留作歷史記錄，不是目前流程。

## 現行流程

1. 演練途中，每句只發出一次角色回應請求。不查學員法規、不走獨立合規審查、不使用退佣即時提示模板。回傳明確標示尚未評估，不把未查核冒充合規通過。仍保留個資和基本回覆格式檢查，AI 自己不得編造專業結論。
2. 按「結束並查看回饋」後，讀取全場逐字稿。每批檢查四句，逐句回傳檢查結果，並作獨立完整性與依據核對。每批都提供全場上下文；後續修正不會抹除原本問題，否定與引用不直接視為違規。
3. 每批完成後加密保存進度，顯示已檢查句數。開始事後檢查後凍結該場對話，避免一邊查核一邊改動。中途出錯不產生評分，可按回饋接續尚未完成的批次。仍受原本兩小時演練保存期限限制，不是永久保存。
4. 所有句子查完才產生評分。問題卡逐項列出句數、原句、問題、理由、可重說版本、官方條文原文與條／款編號。原句由程式依逐字稿帶入，模型不得自行改寫原句。
5. 已確認的違規必須納入專業度評分，引用其中一則原句，不給滿分；僅「待補查」不等同確定違規。先肯定有證據的亮點，再指出調整方向。沒有可信聲音證據的三項星等仍標無法評估，不捏造聲音分數。
6. 示範模式查的是 AI 業務話術，不把使用者扮客戶的疑問算成業務違規，也不替客戶角色評業務能力星等。

## 官方來源界線

事後檢查每批取得全國法規資料庫《保險業務員管理規則》正文，涵蓋第 19 條可擷取且能逐字核對的各款；來源未涵蓋的稅務、商品或其他自律規範列為待補查，不捏造條號或斷言違法。逐句覆蓋與獨立複查不能保證 AI 永不漏判。

範例與痛點分析仍保留回答前查詢；依本次要求，只有演練中的角色對話移除每句法規查詢。

## 試用方式

開啟 http://127.0.0.1:8787/#phone ，Chrome 按 Ctrl+Shift+R，登入並選用自己的已保存免費模型。新開一場練習，先說幾句邀約話術，再按「結束並查看回饋」。觀察演練時不中途指正、回饋中出現問題原句與可展開的法規依據。

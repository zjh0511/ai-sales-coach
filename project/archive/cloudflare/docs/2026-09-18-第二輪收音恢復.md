# 第二輪語音收音恢復

使用者回報第一句辨識、AI 朗讀正常，但第二句無辨識事件，畫面仍顯示聆聽。

本次調整：
- iPhone/iPad 播放結束後等待 3.5 秒切換收音，其他裝置等待 300ms。過渡期間明確顯示「正在切回麥克風」。
- SpeechRecognition 的 start 僅表示服務啟動，收到 audiostart 才顯示麥克風接通。
- 辨識 12 秒無結果則中止該次並重新連接一次；連續失效兩次則明確暫停，不持續假裝聆聽。
- 新增「重新接通收音」：不朗讀開場、不送出舊內容，重新啟動收音。
- 新一輪清空上一句輸入，取消後忽略過期結果，保留已完成對話。
- 更新 Service Worker 及入口模組版本，避免載入舊語音程式。

驗證：60 個自動測試通過，包括模擬第二輪無任何辨識事件、有限重試、手動重接不重送上一句、五輪對話及停止後不得重啟。

限制：以上是程式與模擬事件測試，尚未在使用者實際 iPhone/iPad 驗證。WebKit 問題 321436 描述播放音訊後辨識沒有結果，延遲僅屬相容性處理，不保證所有 iOS 版本恢復。參考：https://bugs.webkit.org/show_bug.cgi?id=321436

實機驗收：更新頁面，開啟演練；AI 回答後待「麥克風已接通」連續測試至少五輪；若無結果，確認自動恢復或明確暫停，使用「重新接通收音」應不產生重複訊息。

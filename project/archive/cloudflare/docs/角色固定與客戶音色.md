# 角色固定與客戶音色（2026-09-12）

本場角色由後端已保存的 mode 決定。客戶模式移除業務邀約技巧，明確處理「哈囉哈囉」「有聽到嗎」與換角色要求；舊歷史中明顯的 AI 業務自介在生成上下文中改回客戶提問。新增輕量角色檢查，明顯誤扮業務時回到客戶提問，不另發 AI 審查請求。這是角色一致性處理，不恢復對學員的逐句合規審查。規則式檢查不能保證辨識所有語意錯位，仍須持續觀察真人情境。

客戶性別保存於本場前端設定，連續語音與手動送出後朗讀均使用同一音色選擇邏輯。男聲優先 Microsoft Zhiwei，女聲優先 Microsoft Hanhan／Yating；只選裝置實際提供的音色。未指定性別或教練示範時保持教練音色。未知名稱不猜性別，找不到對應音色時顯示提示並使用預設中文。設定頁可自行指定男／女音色，偏好依登入帳號存於本裝置。無額外服務、下載或付費音色。

47 項測試通過。以實際免費 Gemini-3.5-Flash-Lite 測試兩種模式各三句：哈囉哈囉、有聽到嗎、請換你當業務，六次均保持指定身分，每次約 1.0–1.3 秒。詳細紀錄 artifacts/role-consistency-live.json。Chrome 已確認新版音色設定選項顯示，真人聽感仍由使用者試聽確認。更新 public 與 dist，未部署。

音色名稱依據：[Microsoft 支援語言與音色](https://support.microsoft.com/en-au/windows/appendix-a-supported-languages-and-voices-4486e345-7730-53da-fcfe-55cc64300f01)。瀏覽器只使用 getVoices() 所提供的 SpeechSynthesisVoice：[MDN voice 屬性](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisUtterance/voice)。

# AI業務教練｜豪老師 Hao+

以語音角色扮演為核心的 AI 業務訓練工具，協助保險業務人員反覆練習邀約、需求探索、
商品說明與異議處理，並在每次演練後得到五項能力評分與教練回饋。

> ⚠️ 本工具僅供自學訓練參考，請勿公開分享生成內容。
> 業務員網路言行不得涉及招攬保險或招募行為。
> 本工具不提供法律、稅務、醫療或財務建議。

---

## 六大功能

| # | 功能 | 說明 |
|---|---|---|
| 1 | 客戶潛在痛點分析 | 輸入客戶背景 → 三個潛在痛點（含推測原因、需求方向、可直接問出口的探索問題）＋ 建議接觸方式 |
| 2 | 電話邀約語音對練 | AI 扮演客戶進行語音通話演練 → 五項評分 ＋ 教練回饋 |
| 3 | 發掘需求角色扮演 | 客戶有隱藏需求，只有問對問題才會鬆口；畫面即時顯示挖到幾項 |
| 4 | 商品行銷語音演練 | 上傳公司教材 → 自動整理 FABE 賣點與常見疑慮 → 針對該商品演練 |
| 5 | 客戶理賠諮詢建議 | 上傳保單條款 → 描述客戶狀況 → 列出可能給付項目、金額、依據條文 |
| 6 | 客戶行銷諮詢建議 | 與教練討論真實客戶狀況，違規建議會被當場糾正 |

## 本機安裝

### 需要

- [Node.js](https://nodejs.org) 20 以上
- Git for Windows（產生憑證用，內含 openssl）
- 一把 AI 服務商的 API 金鑰（在 App 登入畫面輸入，不必寫進檔案）

### 安裝步驟

```bash
git clone <這個 repo 的網址>
cd AiCoach/app
```

產生本機 HTTPS 憑證（手機要用麥克風，一定得走 HTTPS）：

```bash
node tools/gencert.mjs
```

啟動：

```bash
node server.js
```

畫面會印出網址：

| 用途 | 網址 |
|---|---|
| 電腦除錯（免憑證，麥克風可用） | `http://localhost:8444` |
| 手機（需與電腦連同一個 Wi-Fi） | `https://<你的區網IP>:8443` |

手機第一次連線會出現憑證警告 → 「顯示詳細資訊」→「瀏覽此網站」。
之後用分享鍵「加入主畫面」，可當成全螢幕 App 使用。

### 確認一切正常

```bash
node tools/selftest.mjs
```

會真的跑完六大功能共 60 項檢查。也可以只跑單項：`node tools/selftest.mjs 5`。

## 隱私與資料

- **API 金鑰**只存在你自己裝置的瀏覽器，伺服器不落地保存、不寫進日誌。
- **訓練紀錄**存在你自己手機的瀏覽器（localStorage），不會上傳。
- **上傳的文件**存在執行伺服器的那台機器。多人共用同一台伺服器時，
  上傳的商品教材與保單條款**所有使用者都看得到**，請勿上傳含客戶個資的文件。
- **對話內容**會送到你所選服務商的 API 以產生回應。
- 請**不要**輸入客戶的真實姓名、電話、身分證號或病歷等個資，
  演練只需要性別、年齡區間與大略背景。
